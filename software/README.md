# TinyProbe Software

This directory contains the software side of the TinyProbe project. It consists of a Python package, as well as some demo code and thorough unit tests.

## Contents

```bash
software/
├── src/tipy/       # Host Python package
│   ├── control/    # RPC commands, bulk transfer, and protobuf methods
│   ├── hardware/   # FPGA register map and hardware abstraction layer
│   ├── protocol/   # Acquisition protocols and example configurations
│   ├── runtime/    # Device session and received-data parsing
│   ├── tools/      # HDF5 saving, mDNS discovery, logging, and schema generation
│   └── transport/  # Framed link over UDP, TCP, or a dummy implementation
├── demo/           # Example scripts that exercise the package
├── test/           # Unit tests and recorded acquisition fixtures
└── schemas/        # Generated JSON schemas for protocol configs
```

### `src`

`src/tipy` is the host package. `control` sends protobuf RPC commands and receives bulk data. `transport` frames that link over UDP, TCP, or a dummy implementation. `hardware` is the FPGA register map and the abstraction used to write it. `protocol` turns a configuration into setup, acquire, and teardown steps. `runtime` holds the device session and parses received samples. `tools` covers HDF5 saving, mDNS discovery, logging, and schema generation.

### `demo`

Scripts here call the package the way a host application would. `demo_acquisition.py` runs the example protocol from `demo_acquisition.json`. The other scripts are smaller entry points for one area each: `control/` (commands, RPC, and bulk receive), `hardware/` (register map and FPGA HAL), `protocol/`, `runtime/` (session and parser, with an example bitstream), and `tools/` (mDNS and HDF5 saving). Several of them need the `demo` dependency group for matplotlib.

### `test`

`test/` is the pytest suite. Each `test_*.py` file covers one part of the package: the session, parser, protocol, FPGA HAL, register map, RPC server, transports, and HDF5 saving. `data/` holds recorded acquisitions (`acquisition_20260404_002003` and `string_1cm`) used by the saving tests. `common.py` holds fixtures shared by those tests.


## Just targets

Recipes are defined in [`Justfile`](Justfile). Run them from this directory, or from the repository root as `just software <target>`.

The test and lint recipes need the `dev` dependency group:

```bash
uv sync --group dev
```

| Target | What it does |
| --- | --- |
| `test` | Run the pytest suite |
| `lint` | Format, lint, and typecheck |
| `format` | Format with ruff |
| `check` | Lint with ruff, applying fixes |
| `typecheck` | Typecheck with ty |
| `schemas` | Regenerate the JSON schemas in `schemas/` |

`just` with no arguments lists these recipes.


## Using the package

`tipy` requires Python 3.13 or newer. The installable project is this `software/` directory. Add it with [`uv`](https://docs.astral.sh/uv/) from a directory on disk, from a git submodule, or directly from the repository.


### Directory

Point uv at a checkout you already have. An editable install follows later edits in that checkout:

```bash
uv add --editable ./path/to/tinyprobe/software
```

uv records the source in `pyproject.toml`:

```toml
[project]
dependencies = ["tipy"]

[tool.uv.sources]
tipy = { path = "path/to/tinyprobe/software", editable = true }
```

This repository depends on `tipy` the same way: the root project sets `path = "software"`.


### Git submodule

Add the repository as a submodule, then depend on the `software/` directory inside it:

```bash
git submodule add https://github.com/pulp-bio/TinyProbe.git third_party/tinyprobe
uv add --editable ./third_party/tinyprobe/software
```


### Repository

Depend on the Git repository without a local checkout. `subdirectory` selects the `software/` project:

```bash
uv add "git+https://github.com/pulp-bio/TinyProbe.git#subdirectory=software" # Over HTTPS
uv add "git+ssh://git@github.com/pulp-bio/TinyProbe.git#subdirectory=software" # Over SSH
```

Pin a commit, tag, or branch with `--rev`, `--tag`, or `--branch`. The equivalent source entry is:

```toml
[project]
dependencies = ["tipy"]

[tool.uv.sources]
tipy = { git = "https://github.com/pulp-bio/TinyProbe.git", subdirectory = "software", rev = "<commit>" }
```
